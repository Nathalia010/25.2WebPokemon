
# 🎮 Pokémon Storage App - 25.2WebPokemon

Aplicación web desarrollada con **HTML, CSS y JavaScript** que permite buscar información de cualquier Pokémon consumiendo la **PokéAPI**, además de guardar tus Pokémon favoritos utilizando **LocalStorage**.

---

# 📖 Descripción

Pokémon Storage App es una aplicación web interactiva que permite a los usuarios buscar Pokémon por su nombre, visualizar su información básica y crear una lista personalizada de favoritos que permanece almacenada en el navegador.

La aplicación consume datos en tiempo real desde la API oficial de Pokémon y utiliza almacenamiento local para conservar la información incluso después de cerrar la página.

# 📌 Uso

1. Escribe el nombre de un Pokémon (por ejemplo: Pikachu, Charmander o Bulbasaur).
2. Haz clic en **Buscar**.
3. Visualiza la información obtenida desde la PokéAPI.
4. Presiona **Agregar a favoritos** para almacenarlo.
5. Los Pokémon favoritos permanecerán guardados gracias a LocalStorage.
